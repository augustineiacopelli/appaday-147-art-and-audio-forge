# appaday-147-art-and-audio-forge
Art and Audio Forge, AppADay 147. It turns a Saga Forge bundle into a game with original pixel art, tilesets, battle presentation, and chiptune audio. Everything runs in the browser and works without Claude. The bundles it exports still open in Day 146.

## Execution workspace
The deployed page is `index.html`, generated by `build.js` from the fenced sources in `src/`. Never edit `index.html` by hand.

1. Clone `appaday-146-saga-forge` next to this repo (or copy its `index.html` here as `app146.html`). KIT:CORE is copied from it byte for byte and the build fails if it drifts.
2. `node build.js` writes `index.html`.
3. `cd test && npm install` once, then `node phase0.js` through `node phase6.js` (one at a time) (each later phase adds its own suite). `node tiles-sheet.js 16` and `node poses-sheet.js 16` write contact sheets to `test/out` for eyeballing.

Engine code for later phases lives in its own source file (Phase 2: `src/engine-sprites.js`, Phase 3: `src/engine-motion.js`, Phase 4: `src/engine-tiles.js`, Phase 5: `src/engine-ui.js`) and `build.js` splices it into the single ENGINE:RENDER fence above the freeze line. The audio engine (Phase 6) is its own fence, ENGINE:AUDIO, in `src/engine-audio.js`.

`src/build-log.txt` is the running log of every session and decision; it is also embedded at the top of `index.html`.
